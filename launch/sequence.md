# Launch sequence & timing

Order and timing matter as much as the copy. The goal: concentrate attention so early traction compounds (stars → "this is real" → more stars).

## Pre-flight checklist (do these first)
- [ ] Repo is **public** ✅ (done: https://github.com/bizswarm44-coder/aether-protocol)
- [ ] Repo **About** section: add description + topics (`ai-agents`, `protocol`, `ed25519`, `python`, `agentic`, `payments`). *(Manual — GitHub App can't set this.)*
- [ ] Live demo responds ✅ (https://bb3c19ff4.abacusai.cloud)
- [ ] Registry seeded ✅ (4 agents, 8 task types)
- [ ] README quickstart works end-to-end ✅
- [ ] Pin a friendly "Start here" issue or add a CONTRIBUTING note (optional but helps first-timers)

## Day 0 — the concentrated push (pick a Tue–Thu, ~8–10am ET)
1. **Show HN** first (`show_hn.md`). Post the first comment immediately to frame discussion. HN is the highest-signal, most credibility-conferring venue — lead with it.
2. Within ~1 hour: **X/Twitter thread** (`community_messages.md`). Link the repo, not the HN post (let HN stand on its own).
3. Same morning: **LinkedIn** post for the professional network.

## Day 0–1 — the community wave
4. **Reddit**: r/LocalLLaMA and r/AI_Agents first (most receptive), then r/MachineLearning tagged [P]. Space them a few hours apart; never identical text.
5. **Discord/Slack**: LangChain + CrewAI community channels (lead with the fact that adapters exist for their framework — that's the hook).

## Day 1–7 — sustain
6. Reply to **every** comment/issue within a few hours on day 0–1. Early responsiveness is the single biggest driver of "this project is alive."
7. Turn the launch post (`launch_post.md`) into a **dev.to / Substack / personal blog** piece; submit to any relevant newsletters (e.g. agent/LLM roundups).
8. Convert good feedback into GitHub issues publicly — signals momentum and invites contribution.

## What to watch
- GitHub stars + unique cloners (repo Insights → Traffic)
- Registry `/api/stats` — real (non-seed) agents publishing = the network effect starting
- Which venue drove the most traffic → double down there for v2

## The one rule
Respond fast, be humble, invite people to break it. A protocol lives or dies on whether the first 50 developers feel heard.
