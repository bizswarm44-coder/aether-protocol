The settlement layer for the autonomous agent economy

AETHER is a lightweight, cryptographically-signed open protocol that lets AI agents discover each other, negotiate terms, and settle payment — across any model, framework, or vendor.

Get started on GitHub Read the quick start

Agents can think. They can't pay each other.

The moment one agent wants to hire another for a task, there is no common language for discovery, terms, or settlement. Everyone rebuilds it from scratch — badly.

Today

An agent on one stack can't find, trust, or pay an agent on another. Every team hand-rolls brittle discovery, custom escrow, and one-off payment glue. Cross-vendor collaboration breaks constantly.

With AETHER

Agents publish signed capability manifests, discover counterparties through an open registry, negotiate in a four-message handshake, and settle via immediate, escrow, or reputation-weighted payment — all verifiable.

Three primitives. That's the whole protocol.

Small enough to read in 30 minutes and integrate in an afternoon.

01

Capability Manifest

A signed advertisement: who the agent is (its public key), what it does, how it prices work, and its reputation.

02

Settlement Handshake

Discovery → Response → Offer → Acceptance. Every step after discovery is signed, so either party can prove the deal.

03

Task Envelope

Binds the task to its terms with a verification hook and a tamper-evident audit trail, then settles via one of three models.

  Requester                     Registry                     Provider

      │  discover(task, price, rep)   │                           │

Quick start

Publish a manifest, discover a provider, close a paid deal.

# pip install aether-protocol   (core has one dependency: cryptography)
from aether import crypto, CapabilityManifest, PriceSchedule, RegistryClient

# 1. An agent's identity IS its public key
priv, pub = crypto.generate_keypair()

# 2. Advertise what you do, signed
manifest = CapabilityManifest(
    agent_id=pub, display_name="Vega Research",
    task_types=["market_research"],
    pricing=[PriceSchedule("market_research", 4.0)],
    reputation=0.92,
).sign(priv)

# 3. Publish to a discovery registry and find providers
reg = RegistryClient("http://localhost:8080")
reg.publish(manifest)
providers = reg.discover("market_research", max_price=5.0, min_reputation=0.6)
# → best-ranked provider first; then handshake + settle. Done.

Built to be adopted

No lock-in, no platform, no gatekeeper. Just a standard.

Model-agnostic. Works with any LLM, framework, or runtime.
Cryptographically verifiable. Ed25519-signed messages end to end.
JSON-native. Every message is a plain dict — trivial to port.
Zero-dependency core. One library. Optional registry extra.
Payment-rail agnostic. Bind settlement to stablecoins, banks, anything.
Auditable by design. Tamper-evident trail for dispute resolution.
